# Database Crisis – AI Database Rescue Game

---

## 1. 專案介紹 Introduction
* **專案類型**：AI 結合資料庫學習之互動式闖關遊戲。
* **專案內容**：將傳統 DBMS 與 SQL 學習轉化為 Cyberpunk 風格的沉浸式逃脫任務，透過遊戲化方式提升資料庫學習動機與理解能力。
* **核心概念**：
  - ER Modeling
  - SQL Query Practice
  - Database Programming Concepts
  - API & Backend Logic
  - Gamification Design
  - AI-assisted Development

---

## 2. 遊戲背景 Story
* **故事設定**：未來世界中的「Nexus Data Center」遭受大型網路攻擊，企業核心資料系統全面崩潰。
* **玩家身份**：新進 Database Engineer。
* **主要任務**：
  - 修復 ER Model
  - 解決 SQL 問題
  - 修復 Backend API
  - 重建企業資料庫基礎架構

---

## 3. 遊戲關卡設計 Game Levels
### Level 1 – ER Diagram Repair
* 修正錯誤的 Entity Relationship 模型。
* 學習：
  - One-to-One
  - One-to-Many
  - Many-to-Many

### Level 2 – SQL Hacker Battle
* 使用 SQL 指令修復受損資料。
* 強化 SQL 查詢與資料操作能力。

### Level 3 – API Recovery
* 修復 Backend Login Query。
* 恢復系統登入與 API 功能。
